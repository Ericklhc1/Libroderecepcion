# Fronti

Fronti es el asistente operativo flotante del Libro de Recepción.

- Memoria personal: 30 días.
- Memoria compartida: sólo dentro del turno activo.
- El estado operativo real siempre se consulta desde los servicios del Libro.
- Las acciones sensibles requieren confirmación y respetan permisos.
- La sesión se renueva mientras existe actividad reciente del usuario con la aplicación visible.
- `No guardes esto: ...` evita que un mensaje genere memoria.
